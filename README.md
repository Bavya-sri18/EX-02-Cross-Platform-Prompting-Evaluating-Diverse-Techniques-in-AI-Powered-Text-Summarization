# EX-02-Cross-Platform-Prompting-Evaluating-Diverse-Techniques-in-AI-Powered-Text-Summarization

## AIM
To evaluate and compare the effectiveness of prompting techniques (zero-shot, few-shot, chain-of-thought, role-based) across different AI platforms (e.g., ChatGPT, Gemini, Claude, Copilot) in a specific task: text summarization.

## Scenario:
You are part of a content curation team for an educational platform that delivers quick summaries of research papers to undergraduate students. Your task is to summarize a 500-word technical article on "The Basics of Blockchain Technology" using multiple AI platforms and prompting strategies.

Your goal is to determine which combination of prompting technique + platform provides the best summary in terms of:

Accuracy

Coherence

Simplicity

Speed

User experience

## Algorithm

1. Select the Task: Choose Text Summarization as the application and select a technical article on "The Basics of Artificial Intelligence and Machine Learning."

2. Choose AI Platforms: Select the AI platforms for evaluation:
   - ChatGPT
   - Google Gemini
3. Design Prompt Structures: Create prompts using different prompt engineering techniques:
   - Basic Prompt
   - Role Prompt
   - Context Prompt
   - Constraint Prompt
   - Output Format Prompt
   - Final User-Defined Prompt

4. **Execute the Prompts**
   Submit each prompt to both AI platforms using the same source article to ensure a fair comparison.
5. **Collect the Outputs**
   Record the summaries generated by ChatGPT and Gemini for each prompt structure.

6. **Evaluate the Responses**
   Assess each summary based on: Accuracy, Coherence, Simplicity, Speed, User Experience.

7. **Compare the Results**
   Compare the performance of both AI platforms across all prompt structures and identify which platform generates the best summary.

8. **Draw the Conclusion**
   Analyze the results and recommend the most effective prompt structure and AI platform for educational text summarization of agri-tech research content.

## Source Article

Artificial Intelligence (AI) is a branch of computer science that enables machines to perform tasks that normally require human intelligence. These tasks include learning, problem-solving, decision-making, and understanding language. Machine Learning (ML) is a subset of AI that allows computers to learn patterns from data and make predictions without being explicitly programmed for every task. Machine learning mainly includes supervised learning, unsupervised learning, and reinforcement learning. Supervised learning uses labelled data to train models, while unsupervised learning identifies hidden patterns in unlabelled data. Reinforcement learning enables systems to learn through rewards and penalties. AI and ML are widely used in applications such as recommendation systems, fraud detection, image recognition, virtual assistants, and autonomous vehicles. Although these technologies improve efficiency and automate tasks, they also face challenges such as data privacy, bias, high computational costs, and the need for quality training data.

## Prompts

### Basic Prompt
```
Summarize the following article about Artificial Intelligence and Machine Learning in approximately 100 words using simple English.
```

### Role Prompt
```
Act as an experienced Artificial Intelligence professor.

Summarize the following article about Artificial Intelligence and Machine Learning in approximately 100 words using simple language suitable for undergraduate students.
```

### Context Prompt
```
You are an AI professor preparing study materials for undergraduate students who are beginners in Artificial Intelligence.

Summarize the following article about Artificial Intelligence and Machine Learning in approximately 100 words. Explain the important concepts, working principles, and applications in an easy-to-understand manner.
```

### Constraint Prompt
```
Summarize the following article about Artificial Intelligence and Machine Learning by following these constraints:

- Maximum 100 words
- Use simple English
- Avoid unnecessary technical terms
- Include the meaning of AI and ML
- Mention the major types of Machine Learning
- Include at least two applications
- Mention one challenge
- Keep the summary concise and informative.
```

### Output Format Prompt
```
Act as an AI subject expert.

Summarize the following article about Artificial Intelligence and Machine Learning for undergraduate students.

Requirements:
- Maximum 100 words
- Use simple English
- Include important concepts and applications.

Present the response in the following format:

Title
Introduction
Key Concepts
Applications
Challenges
Conclusion
```

### Final User-Defined Prompt
```
Act as an experienced Artificial Intelligence professor and educational content writer.

You are preparing learning materials for undergraduate students who have basic knowledge of computer science.

Summarize the following article about Artificial Intelligence and Machine Learning.

Requirements:
- Maximum 100 words
- Use simple, beginner-friendly English
- Explain AI and ML clearly
- Include the major types of Machine Learning
- Mention important real-world applications
- Highlight the benefits and challenges
- Avoid unnecessary technical jargon
- Ensure factual accuracy and logical flow.

Present the output using the following structure:

Title
Introduction
Key Concepts
Applications
Advantages
Challenges
Conclusion

The final summary should be accurate, concise, coherent, and suitable for undergraduate students.
```

## Conclusion

This experiment demonstrates that prompt engineering significantly improves the quality of AI-generated summaries, even for a more technical, research-oriented topic like multi-crop digital twins and explainable AI. Both platforms produced useful summaries, but quality improved noticeably as prompts moved from basic instructions to role, context, constraint, and output-format specifications.

**For Accuracy and Educational Quality:**
Google Gemini with the Final User-Defined Prompt produced the most comprehensive and well-structured summary, balancing technical accuracy with simplicity, making it the strongest choice for undergraduate educational content on digital twins in agriculture.

**For Quick Understanding and Simplicity:**
Grok generated concise, fast, and easy-to-read summaries, well suited for introductory learning and quick revision, though with slightly less architectural/technical depth than Gemini.

Overall, the **Final User-Defined Prompt** proved the most effective strategy on both platforms, producing summaries that were accurate, coherent, well organized, and suitable for undergraduate students studying AI applications in precision agriculture.

## Result
Thus, different prompt structures were designed and tested for text summarization. The experiment demonstrated how prompts can be progressively improved from basic instructions to detailed user-defined prompts to generate more accurate, relevant, simple, and well-structured summaries.
